Banners

The homepage top banner has 5 slots. Reorder, edit the link, or clear any slot below. To assign an image to an empty slot (or replace one), upload the image file to assets/banners/ on GitHub first, then click "Refresh from GitHub" and enter its filename. A slot left empty is simply skipped on the live site — no blank banner is shown.

Home Page Videos

The homepage "In Motion" section has 4 video slots. Slot 1 is your existing brand video. Empty slots show the Pavnika mark with an authenticity note instead. To add a new video, upload the compressed file to assets/videos/ on GitHub first, then click "Refresh from GitHub" and enter its filename below.

Collections Sidebar Ads

Up to 3 images or videos rotate in the Collections page filter sidebar (desktop only). Images show for 6 seconds; videos play to the end before the next item. Upload the media files to assets/ads/ on GitHub first, then enter their filenames below (e.g. promo1.jpg or reel.mp4). Leave a box empty to skip it.
